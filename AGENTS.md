# kinoko-skills: agent rules

- One skill per folder, named like the skill: `SKILL.md` with frontmatter `name` (= folder) and
  `description` (what and when, with the words a user would use: it is all the model sees until the
  task matches). The body is for the moment the skill is used: concrete steps and commands.
- Nothing personal or secret: the repository is public.
- `bun run check` passes before a commit. New skill: add it to README's table.
